# 🎮 Python Mini Games

🚀 Description
This repository contains a collection of beginner-friendly mini games built using Python. 
These projects focus on strengthening core programming concepts such as loops, conditionals, and user interaction.

🛠 Tech Stack
- Python
- Random Module

🎯 Games Included

## 1. 🎲 Guess the Number
A fun game where the user tries to guess a randomly generated number within a given range.

**Features:**
- User-defined range
- Hints (too high / too low)
- Tracks number of attempts

---

### 2. ✊ Rock Paper Scissors
A classic game where the user plays against the computer.

**Features:**
- User vs Computer gameplay
- Randomized computer choice
- Score tracking system
- Option to quit anytime

---

## 🧠 Concepts Covered
- Loops (while loop)
- Conditional statements (if-else)
- User input handling
- Random number generation
- Basic game logic
